# Prompt patterns

Replace bracketed content with the current request. Use a visual reference alongside each prompt. Treat these as scaffolds rather than fixed scripts.

## New still

Create a single still transparent emoji sticker called [name]. The attached Yako image is the character identity and rendering reference. Preserve the adorable round shaggy brown yak face, cream tousled forelock and beard, tan curved horns, wide ears, broad short tan muzzle and large expressive eyes. [Costume/transformation changes.] [Pose and expression.] [Props with clear contact and orientation.] Exactly [limb count] limbs, with proper two-lobed cloven hooves and one central cleft; no human fingers or thumbs. Match the thick dark-brown outlines, large simple shapes and gentle shading. [Framing] with a compact square silhouette, small margins, full horns/props visible, legible at tiny emoji size. Actual transparent background. [Only relevant exclusions, usually text and scenery.]

## Local revision

Edit the supplied selected image. Change only [specific objects/pose/colors]. [Precise desired result.] Preserve [face, eyes, muzzle, horns, pose, clothing, props, counts, framing as applicable]. Keep the existing cartoon style and transparency. Do not introduce [known likely failure].

Example: Replace the two raised human hands with broad tan cloven hooves: exactly two rounded lobes, one central cleft, no fingers, thumbs or palm creases. Keep both hooves raised in the cinema pose and preserve the face, expression, horns, jacket and composition.

## Multi-reference composition

Image 1 is the base and supplies [Yako, expression, arms, clothing]. Image 2 supplies only [pig/pose/prop]. Preserve image 1's [invariants]. Replace [target] using image 2's [silhouette, expression, colors, direction]. Adjust scale and position only as required for natural contact. Keep transparent background and the established cartoon rendering.

## Example concepts

Read [concepts.md](concepts.md) for the complete 20-concept library and portable visual examples. Use the current direction for an existing concept; consult the revision notes to avoid repeating a superseded execution. Apply the prompt scaffolds above to new concepts.

The user's context matters: smooth-brain meant simplifying concepts; brain-dump meant sharing context; multi-threading meant parallel work. Translate the intended reaction into a readable action instead of relying solely on the emoji label.
