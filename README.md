# imri-plugins

A Bonsai marketplace: plugins and skills by Imri Sofer.

| Item | Kind | What it is |
| --- | --- | --- |
| `plugins/connector-cards` | plugin | Connector Cards: a connected app's own UI in Bonsai's chat. Linear (issue, list, board, project, create), Google Calendar (agenda, month, event, find a time, create) and Slack (channel, thread, activity, composer). One tool call per ask; the plugin reads and writes the app through Bonsai's sign-in, Jev picks the view and fields at runtime, and you navigate inside the card. |

## Add it to Bonsai

App Store → Sources → add `https://github.com/soImri/bonsai-plugins` as a marketplace, approve it, then open App Store → Browse and press Get on Connector Cards. Updates arrive with each push (App Store → Sources → Check for updates).

Or ask Bonsai: "add https://github.com/soImri/bonsai-plugins as a marketplace source".

## Layout

Skills sit at the root (one `SKILL.md` folder each), plugins under `plugins/` (one `kay-plugin.json` folder each). `marketplace.json` names them; `marketplace.index.json` is generated by `node tools/validate.mjs --fix`, which CI checks on every push.
